Strata is an open-source engine that runs the Qwen3.8-Flash-Next Mixture-of-Experts model on consumer hardware by distributing its 24,576 experts across GPU VRAM, system RAM, and SSD, utilizing speculative decoding and adaptive caching to achieve high throughput. The project supports extensive configurations for NVIDIA, AMD, Intel, and older GPUs, offering features like multi-GPU layer splitting, Docker deployment, and compatibility with agent frameworks like Claude Code and Codex. Comprehensive documentation details installation, troubleshooting, community benchmarks, and technical specifics for various quantizations, including Unsloth's 4-bit and 6-bit models and specialized coding variants.
