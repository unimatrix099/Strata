Strata is a local inference engine that enables large Mixture-of-Experts models to run on consumer hardware by distributing the workload across the GPU, RAM, and SSD, utilizing an adaptive expert cache and CPU/GPU parallelism to manage memory constraints. It provides a comprehensive API compatible with OpenAI, Anthropic, and MCP standards, featuring advanced capabilities such as streaming, vision support, conversation caching, and session persistence for efficient agent workflows. The system includes numerous opt-in experimental features for performance tuning, such as rope scaling for extended contexts, speculative drafting optimizations, and specialized memory management strategies, all documented with detailed benchmarks and troubleshooting guides.
