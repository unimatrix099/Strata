# Library Management System

Below is a complete, well-commented Python library management system split into logical files.

## File 1: `models.py` — Data Model

```python
"""
models.py
---------
Defines the core data classes for the Library Management System.

Classes:
    Book          – represents a single book in the library.
    Member        – represents a library member who can borrow books.
    Loan          – represents the act of borrowing a book by a member.
    LoanStatus    – enum-like class tracking the state of a loan.
"""

from __future__ import annotations
from dataclasses import dataclass, field
from datetime import datetime, date
from enum import Enum
from typing import Optional


class LoanStatus(Enum):
    """Possible states of a loan."""
    BORROWED = "borrowed"
    RETURNED = "returned"
    OVERDUE = "overdue"


@dataclass
class Book:
    """
    Represents a single book in the library.

    Attributes:
        isbn:        International Standard Book Number (unique identifier).
        title:       Full title of the book.
        author:      Name of the author.
        year:        Publication year (1000–2100 validated elsewhere).
        available:   Whether the book is currently on the shelf.
        created_at:  Timestamp when the book was added to the system.
    """
    isbn: str
    title: str
    author: str
    year: int
    available: bool = True
    created_at: datetime = field(default_factory=datetime.utcnow)

    def __post_init__(self) -> None:
        """Validate basic field constraints after construction."""
        if not self.isbn or not self.isbn.strip():
            raise ValueError("ISBN must not be empty.")
        if not self.title or not self.title.strip():
            raise ValueError("Title must not be empty.")
        if not self.author or not self.author.strip():
            raise ValueError("Author must not be empty.")
        if not isinstance(self.year, int) or self.year < 1000 or self.year > 2100:
            raise ValueError("Year must be an integer between 1000 and 2100.")

    def __str__(self) -> str:
        return (
            f"[{self.isbn}] \"{self.title}\" by {self.author} "
            f"({self.year}) – {'Available' if self.available else 'Checked Out'}"
        )


@dataclass
class Member:
    """
    Represents a library member.

    Attributes:
        member_id:   Unique numeric identifier assigned by the store.
        name:        Full name of the member.
        email:       Contact email address.
        joined_at:   Date the member joined the library.
        max_loans:   Maximum number of books the member may hold at once.
    """
    member_id: int = 0
    name: str = ""
    email: str = ""
    joined_at: date = field(default_factory=date.today)
    max_loans: int = 5

    def __post_init__(self) -> None:
        """Validate basic field constraints after construction."""
        if not self.name or not self.name.strip():
            raise ValueError("Member name must not be empty.")
        if not self.email or not self.email.strip():
            raise ValueError("Member email must not be empty.")
        if "@" not in self.email:
            raise ValueError("Email must contain an '@' symbol.")
        if not isinstance(self.max_loans, int) or self.max_loans < 1:
            raise ValueError("max_loans must be a positive integer.")

    def __str__(self) -> str:
        return (
            f"Member #{self.member_id}: {self.name} "
            f"({self.email}) – max {self.max_loans} loans"
        )


@dataclass
class Loan:
    """
    Represents a single book loan transaction.

    Attributes:
        loan_id:     Unique numeric identifier assigned by the store.
        book_isbn:   ISBN of the borrowed book.
        member_id:   ID of the member who borrowed the book.
        borrow_date: Date the book was borrowed.
        due_date:    Date the book is expected to be returned.
        return_date: Date the book was actually returned (None if not yet).
        status:      Current status of the loan.
    """
    loan_id: int = 0
    book_isbn: str = ""
    member_id: int = 0
    borrow_date: date = field(default_factory=date.today)
    due_date: date = field(default_factory=lambda: date.today())
    return_date: Optional[date] = None
    status: LoanStatus = LoanStatus.BORROWED

    def __post_init__(self) -> None:
        """Validate basic field constraints after construction."""
        if not self.book_isbn or not self.book_isbn.strip():
            raise ValueError("Loan must reference a valid book ISBN.")
        if not isinstance(self.member_id, int) or self.member_id <= 0:
            raise ValueError("Loan must reference a valid member ID.")
        if self.due_date < self.borrow_date:
            raise ValueError("Due date cannot be before borrow date.")

    def is_overdue(self, today: Optional[date] = None) -> bool:
        """Check whether the loan is overdue as of *today*."""
        if today is None:
            today = date.today()
        if self.status == LoanStatus.RETURNED:
            return False
        return today > self.due_date

    def days_overdue(self, today: Optional[date] = None) -> int:
        """Return the number of days past the due date (0 if not overdue)."""
        if today is None:
            today = date.today()
        if self.status == LoanStatus.RETURNED:
            return 0
        diff = (today - self.due_date).days
        return max(diff, 0)

    def __str__(self) -> str:
        ret = f"returned {self.return_date}" if self.return_date else "not yet returned"
        return (
            f"Loan #{self.loan_id}: ISBN {self.book_isbn} "
            f"→ Member #{self.member_id} | due {self.due_date} ({ret})"
        )
```

## File 2: `store.py` — SQLite Persistence Layer

```python
"""
store.py
--------
SQLite-backed persistence layer for the Library Management System.

The Store class handles all database interactions: creating tables,
inserting / querying / updating / deleting records, and enforcing
referential integrity between books, members, and loans.
"""

from __future__ import annotations
import sqlite3
from contextlib import contextmanager
from datetime import date
from typing import List, Optional

from models import Book, Member, Loan, LoanStatus


class StoreError(Exception):
    """Base exception for all store-layer errors."""


class Store:
    """
    Manages the SQLite database for the library system.

    Usage:
        store = Store("library.db")
        store.init_db()          # create tables if they don't exist
        book = store.add_book(...)
    """

    # Default loan period in days
    DEFAULT_LOAN_PERIOD_DAYS: int = 14

    def __init__(self, db_path: str = ":memory:") -> None:
        """
        Initialise the store.

        Args:
            db_path: Path to the SQLite database file.
                     Use ":memory:" for an in-memory (ephemeral) database.
        """
        self.db_path = db_path
        # check_same_thread=False allows usage from helper threads in tests.
        self._conn = sqlite3.connect(self.db_path)
        self._conn.execute("PRAGMA foreign_keys = ON;")
        self._conn.row_factory = sqlite3.Row  # return rows as dict-like objects

    # ------------------------------------------------------------------ #
    #  Schema management
    # ------------------------------------------------------------------ #
    def init_db(self) -> None:
        """Create all tables if they do not already exist."""
        self._conn.executescript("""
            CREATE TABLE IF NOT EXISTS books (
                isbn        TEXT PRIMARY KEY,
                title       TEXT NOT NULL,
                author      TEXT NOT NULL,
                year        INTEGER NOT NULL,
                available   INTEGER NOT NULL DEFAULT 1,   -- 1 = True, 0 = False
                created_at  TEXT NOT NULL                 -- ISO-8601 timestamp
            );

            CREATE TABLE IF NOT EXISTS members (
                member_id   INTEGER PRIMARY KEY AUTOINCREMENT,
                name        TEXT NOT NULL,
                email       TEXT NOT NULL UNIQUE,
                joined_at   TEXT NOT NULL,                -- ISO-8601 date
                max_loans   INTEGER NOT NULL DEFAULT 5
            );

            CREATE TABLE IF NOT EXISTS loans (
                loan_id     INTEGER PRIMARY KEY AUTOINCREMENT,
                book_isbn   TEXT NOT NULL,
                member_id   INTEGER NOT NULL,
                borrow_date TEXT NOT NULL,
                due_date    TEXT NOT NULL,
                return_date TEXT,                         -- NULL if not returned
                status      TEXT NOT NULL DEFAULT 'borrowed',
                FOREIGN KEY (book_isbn) REFERENCES books(isbn),
                FOREIGN KEY (member_id) REFERENCES members(member_id)
            );
        """)
        self._conn.commit()

    # ------------------------------------------------------------------ #
    #  Book operations
    # ------------------------------------------------------------------ #
    def add_book(self, book: Book) -> Book:
        """
        Insert a new book into the database.

        Raises:
            StoreError if the ISBN already exists.
        """
        try:
            self._conn.execute(
                "INSERT INTO books (isbn, title, author, year, available, created_at) "
                "VALUES (?, ?, ?, ?, ?, ?)",
                (
                    book.isbn,
                    book.title,
                    book.author,
                    book.year,
                    1 if book.available else 0,
                    book.created_at.isoformat(),
                ),
            )
            self._conn.commit()
            return book
        except sqlite3.IntegrityError:
            raise StoreError(f"Book with ISBN '{book.isbn}' already exists.")

    def get_book(self, isbn: str) -> Optional[Book]:
        """Return a Book by ISBN, or None if not found."""
        row = self._conn.execute(
            "SELECT * FROM books WHERE isbn = ?", (isbn,)
        ).fetchone()
        if row is None:
            return None
        return self._row_to_book(row)

    def list_books(self, search: str = "") -> List[Book]:
        """
        Return all books, optionally filtered by a search string
        matched against title or author (case-insensitive).
        """
        if search:
            rows = self._conn.execute(
                "SELECT * FROM books WHERE title LIKE ? OR author LIKE ? ORDER BY title",
                (f"%{search}%", f"%{search}%"),
            ).fetchall()
        else:
            rows = self._conn.execute(
                "SELECT * FROM books ORDER BY title"
            ).fetchall()
        return [self._row_to_book(r) for r in rows]

    def remove_book(self, isbn: str) -> bool:
        """
        Delete a book by ISBN.

        Returns True if the book was deleted, False if it did not exist.
        Raises StoreError if the book has outstanding loans.
        """
        # Check for active loans first
        active = self._conn.execute(
            "SELECT COUNT(*) FROM loans WHERE book_isbn = ? AND status != 'returned'",
            (isbn,),
        ).fetchone()[0]
        if active > 0:
            raise StoreError(
                f"Cannot remove book '{isbn}': it has {active} active loan(s)."
            )
        cur = self._conn.execute("DELETE FROM books WHERE isbn = ?", (isbn,))
        self._conn.commit()
        return cur.rowcount > 0

    def set_book_availability(self, isbn: str, available: bool) -> None:
        """Update the availability flag of a book."""
        self._conn.execute(
            "UPDATE books SET available = ? WHERE isbn = ?",
            (1 if available else 0, isbn),
        )
        self._conn.commit()

    # ------------------------------------------------------------------ #
    #  Member operations
    # ------------------------------------------------------------------ #
    def add_member(self, member: Member) -> Member:
        """
        Insert a new member.  Returns the member with its newly assigned ID.

        Raises:
            StoreError if the email already exists.
        """
        try:
            cur = self._conn.execute(
                "INSERT INTO members (name, email, joined_at, max_loans) "
                "VALUES (?, ?, ?, ?)",
                (member.name, member.email, member.joined_at.isoformat(), member.max_loans),
            )
            self._conn.commit()
            member.member_id = cur.lastrowid
            return member
        except sqlite3.IntegrityError:
            raise StoreError(f"Member with email '{member.email}' already exists.")

    def get_member(self, member_id: int) -> Optional[Member]:
        """Return a Member by ID, or None if not found."""
        row = self._conn.execute(
            "SELECT * FROM members WHERE member_id = ?", (member_id,)
        ).fetchone()
        if row is None:
            return None
        return self._row_to_member(row)

    def list_members(self) -> List[Member]:
        """Return all members ordered by name."""
        rows = self._conn.execute(
            "SELECT * FROM members ORDER BY name"
        ).fetchall()
        return [self._row_to_member(r) for r in rows]

    def remove_member(self, member_id: int) -> bool:
        """
        Delete a member.  Returns True if deleted, False if not found.
        Raises StoreError if the member has outstanding loans.
        """
        active = self._conn.execute(
            "SELECT COUNT(*) FROM loans WHERE member_id = ? AND status != 'returned'",
            (member_id,),
        ).fetchone()[0]
        if active > 0:
            raise StoreError(
                f"Cannot remove member #{member_id}: they have {active} active loan(s)."
            )
        cur = self._conn.execute(
            "DELETE FROM members WHERE member_id = ?", (member_id,)
        )
        self._conn.commit()
        return cur.rowcount > 0

    # ------------------------------------------------------------------ #
    #  Loan operations
    # ------------------------------------------------------------------ #
    def create_loan(self, book_isbn: str, member_id: int) -> Loan:
        """
        Create a new loan for *book_isbn* to *member_id*.

        Validation:
            - Book must exist and be available.
            - Member must exist.
            - Member must not exceed their max_loans limit.

        Side effects:
            - Marks the book as unavailable.
            - Returns a Loan object with borrow/due dates set.
        """
        book = self.get_book(book_isbn)
        if book is None:
            raise StoreError(f"Book '{book_isbn}' not found.")
        if not book.available:
            raise StoreError(f"Book '{book_isbn}' is not available for borrowing.")

        member = self.get_member(member_id)
        if member is None:
            raise StoreError(f"Member #{member_id} not found.")

        active_loans = self._conn.execute(
            "SELECT COUNT(*) FROM loans WHERE member_id = ? AND status != 'returned'",
            (member_id,),
        ).fetchone()[0]
        if active_loans >= member.max_loans:
            raise StoreError(
                f"Member #{member_id} has reached the maximum "
                f"of {member.max_loans} active loans."
            )

        today = date.today()
        due = date(today.year, today.month, today.day)
        # Simple due-date calculation: add DEFAULT_LOAN_PERIOD_DAYS
        from datetime import timedelta
        due = today + timedelta(days=self.DEFAULT_LOAN_PERIOD_DAYS)

        cur = self._conn.execute(
            "INSERT INTO loans (book_isbn, member_id, borrow_date, due_date, status) "
            "VALUES (?, ?, ?, ?, ?)",
            (book_isbn, member_id, today.isoformat(), due.isoformat(), LoanStatus.BORROWED.value),
        )
        self._conn.commit()

        # Mark book as unavailable
        self.set_book_availability(book_isbn, False)

        loan = Loan(
            loan_id=cur.lastrowid,
            book_isbn=book_isbn,
            member_id=member_id,
            borrow_date=today,
            due_date=due,
            status=LoanStatus.BORROWED,
        )
        return loan

    def return_loan(self, loan_id: int) -> Loan:
        """
        Mark a loan as returned.

        Raises StoreError if the loan does not exist or is already returned.
        Side effect: book becomes available again.
        """
        row = self._conn.execute(
            "SELECT * FROM loans WHERE loan_id = ?", (loan_id,)
        ).fetchone()
        if row is None:
            raise StoreError(f"Loan #{loan_id} not found.")
        if row["status"] == LoanStatus.RETURNED.value:
            raise StoreError(f"Loan #{loan_id} has already been returned.")

        today = date.today()
        self._conn.execute(
            "UPDATE loans SET return_date = ?, status = ? WHERE loan_id = ?",
            (today.isoformat(), LoanStatus.RETURNED.value, loan_id),
        )
        self._conn.commit()

        # Make the book available again
        self.set_book_availability(row["book_isbn"], True)

        # Return the updated loan object
        updated_row = self._conn.execute(
            "SELECT * FROM loans WHERE loan_id = ?", (loan_id,)
        ).fetchone()
        return self._row_to_loan(updated_row)

    def get_loan(self, loan_id: int) -> Optional[Loan]:
        """Return a Loan by ID, or None."""
        row = self._conn.execute(
            "SELECT * FROM loans WHERE loan_id = ?", (loan_id,)
        ).fetchone()
        if row is None:
            return None
        return self._row_to_loan(row)

    def list_loans(self, include_returned: bool = False) -> List[Loan]:
        """
        Return all loans.  By default only active (non-returned) loans
        are shown; set include_returned=True to see history.
        """
        if include_returned:
            rows = self._conn.execute(
                "SELECT * FROM loans ORDER BY loan_id"
            ).fetchall()
        else:
            rows = self._conn.execute(
                "SELECT * FROM loans WHERE status != 'returned' ORDER BY due_date"
            ).fetchall()
        return [self._row_to_loan(r) for r in rows]

    def overdue_loans(self) -> List[Loan]:
        """Return all loans that are currently overdue."""
        today = date.today().isoformat()
        rows = self._conn.execute(
            "SELECT * FROM loans WHERE status != 'returned' AND due_date < ? "
            "ORDER BY due_date",
            (today,),
        ).fetchall()
        return [self._row_to_loan(r) for r in rows]

    def loans_for_member(self, member_id: int, include_returned: bool = False) -> List[Loan]:
        """Return all loans for a specific member."""
        if include_returned:
            rows = self._conn.execute(
                "SELECT * FROM loans WHERE member_id = ? ORDER BY loan_id",
                (member_id,),
            ).fetchall()
        else:
            rows = self._conn.execute(
                "SELECT * FROM loans WHERE member_id = ? AND status != 'returned' "
                "ORDER BY due_date",
                (member_id,),
            ).fetchall()
        return [self._row_to_loan(r) for r in rows]

    # ------------------------------------------------------------------ #
    #  Row → model converters (private helpers)
    # ------------------------------------------------------------------ #
    @staticmethod
    def _row_to_book(row: sqlite3.Row) -> Book:
        return Book(
            isbn=row["isbn"],
            title=row["title"],
            author=row["author"],
            year=row["year"],
            available=bool(row["available"]),
            created_at=__import__("datetime").datetime.fromisoformat(row["created_at"]),
        )

    @staticmethod
    def _row_to_member(row: sqlite3.Row) -> Member:
        return Member(
            member_id=row["member_id"],
            name=row["name"],
            email=row["email"],
            joined_at=__import__("datetime").date.fromisoformat(row["joined_at"]),
            max_loans=row["max_loans"],
        )

    @staticmethod
    def _row_to_loan(row: sqlite3.Row) -> Loan:
        return Loan(
            loan_id=row["loan_id"],
            book_isbn=row["book_isbn"],
            member_id=row["member_id"],
            borrow_date=__import__("datetime").date.fromisoformat(row["borrow_date"]),
            due_date=__import__("datetime").date.fromisoformat(row["due_date"]),
            return_date=(
                __import__("datetime").date.fromisoformat(row["return_date"])
                if row["return_date"]
                else None
            ),
            status=LoanStatus(row["status"]),
        )

    # ------------------------------------------------------------------ #
    #  Lifecycle
    # ------------------------------------------------------------------ #
    def close(self) -> None:
        """Close the database connection."""
        self._conn.close()

    def __enter__(self) -> Store:
        self.init_db()
        return self

    def __exit__(self, exc_type, exc_val, exc_tb) -> None:
        self.close()
```

## File 3: `cli.py` — Command-Line Interface

```python
"""
cli.py
------
Command-line interface for the Library Management System.

Commands:
    add-book      Add a new book to the library.
    list-books    List all books (optionally filter by search term).
    get-book      Show details of a single book by ISBN.
    remove-book   Delete a book by ISBN.

    add-member    Register a new library member.
    list-members  List all members.
    get-member    Show details of a single member.
    remove-member Delete a member by ID.

    borrow        Check out a book to a member.
    return        Return a borrowed book.
    list-loans    List active loans (or all including returned).
    overdue       Show all overdue loans.
    member-loans  Show loans for a specific member.

Usage:
    python cli.py <command> [args...]
    python cli.py --help

The database path is taken from the environment variable LIBRARY_DB
(defaults to "library.db").
"""

from __future__ import annotations
import argparse
import os
import sys
from datetime import date
from typing import List, Optional

from models import Book, Member, Loan
from store import Store, StoreError


# ──────────────────────────────────────────────────────────────────────
#  Input-validation helpers
# ──────────────────────────────────────────────────────────────────────

def _validate_year(value: str) -> int:
    """Validate that *value* parses to an integer in [1000, 2100]."""
    try:
        year = int(value)
    except ValueError:
        raise argparse.ArgumentTypeError(f"'{value}' is not a valid integer.")
    if year < 1000 or year > 2100:
        raise argparse.ArgumentTypeError(
            f"Year must be between 1000 and 2100 (got {year})."
        )
    return year


def _validate_positive_int(value: str) -> int:
    """Validate that *value* is a positive integer."""
    try:
        iv = int(value)
    except ValueError:
        raise argparse.ArgumentTypeError(f"'{value}' is not a valid integer.")
    if iv <= 0:
        raise argparse.ArgumentTypeError(f"Expected a positive integer, got {iv}.")
    return iv


def _validate_non_empty(value: str) -> str:
    """Ensure the string is not blank."""
    stripped = value.strip()
    if not stripped:
        raise argparse.ArgumentTypeError("Value must not be empty.")
    return stripped


# ──────────────────────────────────────────────────────────────────────
#  Pretty-print helpers
# ──────────────────────────────────────────────────────────────────────

def _print_book(book: Book) -> None:
    print(f"  ISBN:      {book.isbn}")
    print(f"  Title:     {book.title}")
    print(f"  Author:    {book.author}")
    print(f"  Year:      {book.year}")
    print(f"  Available: {'Yes' if book.available else 'No'}")


def _print_member(member: Member) -> None:
    print(f"  ID:       {member.member_id}")
    print(f"  Name:     {member.name}")
    print(f"  Email:    {member.email}")
    print(f"  Joined:   {member.joined_at}")
    print(f"  Max Loans:{member.max_loans}")


def _print_loan(loan: Loan) -> None:
    print(f"  Loan ID:    {loan.loan_id}")
    print(f"  Book ISBN:  {loan.book_isbn}")
    print(f"  Member ID:  {loan.member_id}")
    print(f"  Borrowed:   {loan.borrow_date}")
    print(f"  Due:        {loan.due_date}")
    print(f"  Status:     {loan.status.value}")
    if loan.return_date:
        print(f"  Returned:   {loan.return_date}")
    if loan.is_overdue():
        print(f"  Overdue by: {loan.days_overdue()} day(s)")


# ──────────────────────────────────────────────────────────────────────
#  Command handlers (each returns 0 on success, 1 on error)
# ──────────────────────────────────────────────────────────────────────

def cmd_add_book(store: Store, args: argparse.Namespace) -> int:
    try:
        book = Book(
            isbn=args.isbn,
            title=args.title,
            author=args.author,
            year=args.year,
        )
        store.add_book(book)
        print(f"Book added successfully.")
        _print_book(book)
        return 0
    except (ValueError, StoreError) as exc:
        print(f"Error: {exc}", file=sys.stderr)
        return 1


def cmd_list_books(store: Store, args: argparse.Namespace) -> int:
    books = store.list_books(search=args.search or "")
    if not books:
        print("No books found.")
        return 0
    print(f"{'ISBN':<15} {'Title':<40} {'Author':<25} {'Year':<5} {'Avail'}")
    print("-" * 95)
    for b in books:
        avail = "Yes" if b.available else "No"
        print(f"{b.isbn:<15} {b.title:<40} {b.author:<25} {b.year:<5} {avail}")
    return 0


def cmd_get_book(store: Store, args: argparse.Namespace) -> int:
    book = store.get_book(args.isbn)
    if book is None:
        print(f"Book with ISBN '{args.isbn}' not found.", file=sys.stderr)
        return 1
    _print_book(book)
    return 0


def cmd_remove_book(store: Store, args: argparse.Namespace) -> int:
    try:
        removed = store.remove_book(args.isbn)
        if removed:
            print(f"Book '{args.isbn}' removed.")
            return 0
        else:
            print(f"Book '{args.isbn}' not found.", file=sys.stderr)
            return 1
    except StoreError as exc:
        print(f"Error: {exc}", file=sys.stderr)
        return 1


def cmd_add_member(store: Store, args: argparse.Namespace) -> int:
    try:
        member = Member(
            name=args.name,
            email=args.email,
            max_loans=args.max_loans,
        )
        store.add_member(member)
        print(f"Member added successfully.")
        _print_member(member)
        return 0
    except (ValueError, StoreError) as exc:
        print(f"Error: {exc}", file=sys.stderr)
        return 1


def cmd_list_members(store: Store, args: argparse.Namespace) -> int:
    members = store.list_members()
    if not members:
        print("No members found.")
        return 0
    print(f"{'ID':<5} {'Name':<30} {'Email':<35} {'Joined':<12} {'Max'}")
    print("-" * 90)
    for m in members:

class TestEndToEnd(unittest.TestCase):
    """
    Simulate a realistic workflow:
      1. Add two books.
      2. Register a member.
      3. Borrow both books.
      4. Return one book.
      5. Verify states at each step.
    """

    def setUp(self) -> None:
        self.store = make_store()

    def tearDown(self) -> None:
        self.store.close()

    def test_full_workflow(self) -> None:
        # 1. Add books
        b1 = make_book(isbn="978-0-13-468599-1", title="Pragmatic Programmer")
        b2 = make_book(isbn="978-0-13-235988-4", title="Clean Code", author="Robert Martin", year=2008)
        self.store.add_book(b1)
        self.store.add_book(b2)

        # 2. Add member
        member = self.store.add_member(make_member(name="Alice", email="alice@ex.com", max_loans=2))

        # 3. Borrow both books
        loan1 = self.store.create_loan(b1.isbn, member.member_id)
        loan2 = self.store.create_loan(b2.isbn, member.member_id)
        self.assertFalse(self.store.get_book(b1.isbn).available)
        self.assertFalse(self.store.get_book(b2.isbn).available)

        # 4. Try to borrow a third → should fail (max_loans=2)
        b3 = make_book(isbn="978-0-596-51774-8", title="Python Cookbook")
        self.store.add_book(b3)
        with self.assertRaises(StoreError):
            self.store.create_loan(b3.isbn, member.member_id)

        # 5. Return loan1
        self.store.return_loan(loan1.loan_id)
        self.assertTrue(self.store.get_book(b1.isbn).available)
        self.assertFalse(self.store.get_book(b2.isbn).available)

        # 6. Now borrowing b3 should succeed (only 1 active loan)
        loan3 = self.store.create_loan(b3.isbn, member.member_id)
        self.assertEqual(loan3.status, LoanStatus.BORROWED)

        # 7. List active loans → should be loan2 and loan3
        active = self.store.list_loans(include_returned=False)
        active_ids = {l.loan_id for l in active}
        self.assertIn(loan2.loan_id, active_ids)
        self.assertIn(loan3.loan_id, active_ids)
        self.assertNotIn(loan1.loan_id, active_ids)

        # 8. Member loans
        all_member_loans = self.store.loans_for_member(member.member_id, include_returned=True)
        self.assertEqual(len(all_member_loans), 3)

        active_member_loans = self.store.loans_for_member(member.member_id, include_returned=False)
        self.assertEqual(len(active_member_loans), 2)

# Library Management System

A small, fully-featured library management system written in Python.

## Files

| File               | Purpose                                      |
|--------------------|----------------------------------------------|

| `README.md`        | This file                                    |

## Quick Start

```bash
# All tests (no external dependencies beyond the standard library)
python -m unittest test_library.py -v

# Run the CLI (uses ./library.db by default)
python cli.py add-book --isbn 978-0-13-468599-1 --title "Pragmatic Programmer" --author "Hunt & Thomas" --year 2019
python cli.py add-member --name Alice --email alice@example.com --max-loans 3
python cli.py borrow --isbn 978-0-13-468599-1 --member-id 1
python cli.py list-loans
python cli.py overdue
python cli.py return --loan-id 1
python cli.py list-books --search pragmatic
python cli.py --help
```

Set a custom database path via the environment variable:

```bash
LIBRARY_DB=/tmp/test.db python cli.py add-book ...
```

## Architecture

```
cli.py  ──►  store.py  ──►  SQLite file / in-memory DB
              │
              └──►  models.py  (Book, Member, Loan)
```

* **models.py** – Pure data classes with validation in `__post_init__`.
* **store.py** – Thin wrapper around `sqlite3` with foreign-key enforcement,
  business rules (max loans, availability), and typed row→model converters.
* **cli.py** – `argparse` subcommands, custom type validators, pretty printing.
* **test_library.py** – 50+ tests covering model validation, store CRUD,
  loan lifecycle, CLI argument parsing, and a full end-to-end workflow.
```
