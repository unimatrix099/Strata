Strata is an open-source inference engine that enables large Mixture-of-Experts models like Qwen3.8-Flash-Next to run on consumer hardware by distributing model weights across GPU VRAM, system RAM, and SSDs while using speculative decoding to maintain high throughput. The documentation details extensive configuration options for optimizing performance across various hardware setups, including multi-GPU splits, low-RAM modes, and specific tuning for NVIDIA, AMD, and Intel Arc architectures. Additionally, it provides comprehensive guides for installation, API usage, community benchmarking standards, and troubleshooting to help users deploy and maintain the engine effectively.
