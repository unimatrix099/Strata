Strata is an open-source inference engine that enables large Mixture-of-Experts models like Qwen3.8-Flash-Next to run on consumer hardware by distributing the workload across the GPU, RAM, and SSD, utilizing techniques such as speculative decoding and adaptive expert caching to optimize speed and memory usage. The software supports both NVIDIA and AMD GPUs on Windows and Linux, offering a comprehensive setup process, a web interface, and API compatibility with OpenAI and Anthropic standards, including features for structured JSON output and lazy loading. Detailed documentation covers installation, troubleshooting common hardware and software issues, and advanced configuration options for multi-GPU setups, Docker containers, and performance tuning.
