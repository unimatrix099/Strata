Strata is an open-source inference engine that enables large Mixture-of-Experts models like Qwen3.8-Flash-Next to run on consumer hardware by distributing the workload across the GPU, RAM, and SSD, utilizing techniques such as speculative decoding and adaptive expert caching. The documentation provides comprehensive installation and troubleshooting guides for Windows and Linux, detailing requirements for NVIDIA and AMD GPUs, multi-GPU configurations, and Docker setups, while also explaining the underlying architecture that allows the CPU to compute uncached experts in parallel with the GPU. Additionally, it covers advanced features including experimental speed projection, structured JSON output validation, API monitoring, and performance optimizations like expert cache rotation and disjoint slot management to maximize throughput and memory efficiency.
