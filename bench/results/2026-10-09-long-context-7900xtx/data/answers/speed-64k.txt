Strata is an open-source inference engine that enables large Mixture-of-Experts models like Qwen3.8-Flash-Next to run on consumer hardware by distributing the model's experts across GPU VRAM, system RAM, and SSD storage. The documentation details its technical architecture, including speculative decoding, adaptive expert caching, and support for various quantization formats, alongside comprehensive guides for installation, configuration, and API usage on Windows, Linux, and Intel Arc GPUs. It also provides community benchmark results, troubleshooting steps for common hardware limitations, and instructions for integrating the engine with external tools via OpenAI-compatible APIs and MCP servers.
