Strata is an open-source inference engine that enables large Mixture-of-Experts models like Qwen3.8-Flash-Next to run on consumer hardware by distributing model weights across GPU VRAM, system RAM, and SSDs while using speculative decoding to accelerate generation. The documentation details extensive configuration options for optimizing performance across various hardware setups, including multi-GPU splits, low-RAM modes, and specific tuning for NVIDIA, AMD, and Intel Arc architectures. It also provides comprehensive guides for installation, API usage, community benchmarking standards, and troubleshooting common issues related to memory management and driver compatibility.
