## File 1: `models.py` — Data Model

```python
"""
models.py
---------
Defines the core data classes for the Library Management System.

Classes:
    Book          – represents a single book in the library catalog.
    Member        – represents a library member who can borrow books.
    Loan          – represents a loan transaction (book borrowed by a member).

Each class is a plain data container with basic validation helpers.
"""

from __future__ import annotations

from dataclasses import dataclass, field
from datetime import datetime, date
from typing import Optional


# ---------------------------------------------------------------------------
# Constants
# ---------------------------------------------------------------------------

# Maximum number of days a book can be borrowed before it becomes overdue.
LOAN_PERIOD_DAYS: int = 14

# Maximum number of books a single member may have checked out at once.
MAX_BOOKS_PER_MEMBER: int = 5


# ---------------------------------------------------------------------------
# Book
# ---------------------------------------------------------------------------

@dataclass
class Book:
    """
    Represents a book in the library catalog.

    Attributes:
        id       : unique integer identifier (auto-assigned by the store).
        title    : the book's title (non-empty string).
        author   : the book's author (non-empty string).
        isbn     : ISBN-10 or ISBN-13 as a string (non-empty).
        available: whether the book is currently available for borrowing.
    """
    id: int = 0
    title: str = ""
    author: str = ""
    isbn: str = ""
    available: bool = True

    def validate(self) -> None:
        """Raise ValueError if any required field is missing or invalid."""
        if not self.title or not self.title.strip():
            raise ValueError("Book title must be a non-empty string.")
        if not self.author or not self.author.strip():
            raise ValueError("Book author must be a non-empty string.")
        if not self.isbn or not self.isbn.strip():
            raise ValueError("Book ISBN must be a non-empty string.")


# ---------------------------------------------------------------------------
# Member
# ---------------------------------------------------------------------------

@dataclass
class Member:
    """
    Represents a library member.

    Attributes:
        id        : unique integer identifier (auto-assigned by the store).
        name      : the member's full name (non-empty string).
        email     : the member's email address (non-empty string).
        joined_on : date the member joined the library.
    """
    id: int = 0
    name: str = ""
    email: str = ""
    joined_on: date = field(default_factory=date.today)

    def validate(self) -> None:
        """Raise ValueError if any required field is missing or invalid."""
        if not self.name or not self.name.strip():
            raise ValueError("Member name must be a non-empty string.")
        if not self.email or not self.email.strip():
            raise ValueError("Member email must be a non-empty string.")
        # Basic email sanity check – does not validate RFC 5322 fully.
        if "@" not in self.email:
            raise ValueError("Member email must contain an '@' symbol.")


# ---------------------------------------------------------------------------
# Loan
# ---------------------------------------------------------------------------

@dataclass
class Loan:
    """
    Represents a single loan transaction.

    Attributes:
        id         : unique integer identifier (auto-assigned by the store).
        book_id    : foreign key to Book.id.
        member_id  : foreign key to Member.id.
        loan_date  : the date the book was borrowed.
        due_date   : the date the book must be returned.
        returned   : True if the book has been returned.
        returned_date: the date the book was returned (None if not yet returned).
    """
    id: int = 0
    book_id: int = 0
    member_id: int = 0
    loan_date: date = field(default_factory=date.today)
    due_date: date = field(default_factory=lambda: date.today())
    returned: bool = False
    returned_date: Optional[date] = None

    def validate(self) -> None:
        """Raise ValueError if loan data is inconsistent."""
        if self.book_id <= 0:
            raise ValueError("Loan must reference a valid book_id.")
        if self.member_id <= 0:
            raise ValueError("Loan must reference a valid member_id.")
        if self.due_date < self.loan_date:
            raise ValueError("Due date must be on or after the loan date.")

    def is_overdue(self, reference_date: Optional[date] = None) -> bool:
        """
        Return True if the loan is overdue as of *reference_date*
        (defaults to today).
        """
        if self.returned:
            return False
        ref = reference_date or date.today()
        return ref > self.due_date

    def days_overdue(self, reference_date: Optional[date] = None) -> int:
        """
        Return the number of days past the due date (0 if not overdue).
        """
        if self.returned:
            return 0
        ref = reference_date or date.today()
        if ref <= self.due_date:
            return 0
        return (ref - self.due_date).days
```

## File 2: `store.py` — SQLite Persistence Layer

```python
"""
store.py
--------
SQLite-backed persistence layer for the Library Management System.

The LibraryStore class provides CRUD operations for Books, Members, and Loans,
with built-in referential integrity checks (foreign keys) and transactional
safety.
"""

from __future__ import annotations

import sqlite3
from contextlib import contextmanager
from datetime import date, timedelta
from pathlib import Path
from typing import List, Optional

from models import Book, Member, Loan, LOAN_PERIOD_DAYS, MAX_BOOKS_PER_MEMBER


class LibraryStore:
    """
    Manages all SQLite interactions for the library system.

    Parameters:
        db_path : path to the SQLite database file. Use ":memory:" for an
                  in-memory database (ideal for testing).
    """

    def __init__(self, db_path: str = "library.db") -> None:
        self._db_path = db_path
        self._conn: Optional[sqlite3.Connection] = None
        self._ensure_schema()

    # ------------------------------------------------------------------
    # Connection helpers
    # ------------------------------------------------------------------

    def _get_connection(self) -> sqlite3.Connection:
        """Return a live SQLite connection, creating one if needed."""
        if self._conn is None:
            self._conn = sqlite3.connect(self._db_path)
            # Enable foreign-key enforcement (off by default in SQLite).
            self._conn.execute("PRAGMA foreign_keys = ON;")
            # Return rows as sqlite3.Row objects (dict-like access).
            self._conn.row_factory = sqlite3.Row
        return self._conn

    @contextmanager
    def _transaction(self) -> sqlite3.Cursor:
        """
        Context manager that yields a cursor and commits on success,
        rolls back on exception.
        """
        conn = self._get_connection()
        cursor = conn.cursor()
        try:
            yield cursor
            conn.commit()
        except Exception:
            conn.rollback()
            raise

    def close(self) -> None:
        """Close the database connection if it is open."""
        if self._conn is not None:
            self._conn.close()
            self._conn = None

    # ------------------------------------------------------------------
    # Schema creation
    # ------------------------------------------------------------------

    def _ensure_schema(self) -> None:
        """Create all tables if they do not already exist."""
        conn = self._get_connection()
        conn.executescript(
            """
            CREATE TABLE IF NOT EXISTS books (
                id        INTEGER PRIMARY KEY AUTOINCREMENT,
                title     TEXT    NOT NULL,
                author    TEXT    NOT NULL,
                isbn      TEXT    NOT NULL UNIQUE,
                available INTEGER NOT NULL DEFAULT 1
            );

            CREATE TABLE IF NOT EXISTS members (
                id        INTEGER PRIMARY KEY AUTOINCREMENT,
                name      TEXT    NOT NULL,
                email     TEXT    NOT NULL UNIQUE,
                joined_on TEXT    NOT NULL
            );

            CREATE TABLE IF NOT EXISTS loans (
                id            INTEGER PRIMARY KEY AUTOINCREMENT,
                book_id       INTEGER NOT NULL,
                member_id     INTEGER NOT NULL,
                loan_date     TEXT    NOT NULL,
                due_date      TEXT    NOT NULL,
                returned      INTEGER NOT NULL DEFAULT 0,
                returned_date TEXT,
                FOREIGN KEY (book_id)   REFERENCES books(id),
                FOREIGN KEY (member_id) REFERENCES members(id)
            );

            -- Indexes for common look-ups
            CREATE INDEX IF NOT EXISTS idx_books_title    ON books(title);
            CREATE INDEX IF NOT EXISTS idx_books_author   ON books(author);
            CREATE INDEX IF NOT EXISTS idx_loans_book     ON loans(book_id);
            CREATE INDEX IF NOT EXISTS idx_loans_member   ON loans(member_id);
            CREATE INDEX IF NOT EXISTS idx_loans_due      ON loans(due_date);
            """
        )
        conn.commit()

    # ------------------------------------------------------------------
    # Row → model converters
    # ------------------------------------------------------------------

    @staticmethod
    def _row_to_book(row: sqlite3.Row) -> Book:
        return Book(
            id=row["id"],
            title=row["title"],
            author=row["author"],
            isbn=row["isbn"],
            available=bool(row["available"]),
        )

    @staticmethod
    def _row_to_member(row: sqlite3.Row) -> Member:
        return Member(
            id=row["id"],
            name=row["name"],
            email=row["email"],
            joined_on=date.fromisoformat(row["joined_on"]),
        )

    @staticmethod
    def _row_to_loan(row: sqlite3.Row) -> Loan:
        returned_date = None
        if row["returned_date"] is not None:
            returned_date = date.fromisoformat(row["returned_date"])
        return Loan(
            id=row["id"],
            book_id=row["book_id"],
            member_id=row["member_id"],
            loan_date=date.fromisoformat(row["loan_date"]),
            due_date=date.fromisoformat(row["due_date"]),
            returned=bool(row["returned"]),
            returned_date=returned_date,
        )

    # ------------------------------------------------------------------
    # Book CRUD
    # ------------------------------------------------------------------

    def add_book(self, title: str, author: str, isbn: str) -> Book:
        """Insert a new book and return it with its assigned id."""
        book = Book(title=title, author=author, isbn=isbn)
        book.validate()
        with self._transaction() as cur:
            cur.execute(
                "INSERT INTO books (title, author, isbn, available) VALUES (?, ?, ?, 1);",
                (book.title, book.author, book.isbn),
            )
            book.id = cur.lastrowid
        return book

    def get_book(self, book_id: int) -> Optional[Book]:
        """Return a single Book by id, or None if not found."""
        conn = self._get_connection()
        cur = conn.execute("SELECT * FROM books WHERE id = ?;", (book_id,))
        row = cur.fetchone()
        return self._row_to_book(row) if row else None

    def list_books(self, search: Optional[str] = None) -> List[Book]:
        """
        Return all books. If *search* is given, filter by title, author,
        or ISBN containing the search string (case-insensitive).
        """
        conn = self._get_connection()
        if search:
            pattern = f"%{search}%"
            cur = conn.execute(
                "SELECT * FROM books WHERE title LIKE ? OR author LIKE ? OR isbn LIKE ? ORDER BY title;",
                (pattern, pattern, pattern),
            )
        else:
            cur = conn.execute("SELECT * FROM books ORDER BY title;")
        return [self._row_to_book(row) for row in cur.fetchall()]

    def update_book(self, book_id: int, title: str, author: str, isbn: str) -> Book:
        """Update an existing book's metadata. Raises if book not found."""
        book = Book(title=title, author=author, isbn=isbn)
        book.validate()
        with self._transaction() as cur:
            cur.execute(
                "UPDATE books SET title = ?, author = ?, isbn = ? WHERE id = ?;",
                (book.title, book.author, book.isbn, book_id),
            )
            if cur.rowcount == 0:
                raise LookupError(f"Book with id {book_id} not found.")
        updated = self.get_book(book_id)
        assert updated is not None
        return updated

    def delete_book(self, book_id: int) -> None:
        """Delete a book. Raises if the book has active loans."""
        with self._transaction() as cur:
            # Check for active (unreturned) loans first.
            cur.execute(
                "SELECT COUNT(*) FROM loans WHERE book_id = ? AND returned = 0;",
                (book_id,),
            )
            active = cur.fetchone()[0]
            if active > 0:
                raise ValueError(
                    f"Cannot delete book {book_id}: it has {active} active loan(s)."
                )
            cur.execute("DELETE FROM loans WHERE book_id = ?;", (book_id,))
            cur.execute("DELETE FROM books WHERE id = ?;", (book_id,))
            if cur.rowcount == 0:
                raise LookupError(f"Book with id {book_id} not found.")

    # ------------------------------------------------------------------
    # Member CRUD
    # ------------------------------------------------------------------

    def add_member(self, name: str, email: str) -> Member:
        """Insert a new member and return it with its assigned id."""
        member = Member(name=name, email=email)
        member.validate()
        with self._transaction() as cur:
            cur.execute(
                "INSERT INTO members (name, email, joined_on) VALUES (?, ?, ?);",
                (member.name, member.email, member.joined_on.isoformat()),
            )
            member.id = cur.lastrowid
        return member

    def get_member(self, member_id: int) -> Optional[Member]:
        """Return a single Member by id, or None if not found."""
        conn = self._get_connection()
        cur = conn.execute("SELECT * FROM members WHERE id = ?;", (member_id,))
        row = cur.fetchone()
        return self._row_to_member(row) if row else None

    def list_members(self, search: Optional[str] = None) -> List[Member]:
        """Return all members. Optionally filter by name or email."""
        conn = self._get_connection()
        if search:
            pattern = f"%{search}%"
            cur = conn.execute(
                "SELECT * FROM members WHERE name LIKE ? OR email LIKE ? ORDER BY name;",
                (pattern, pattern),
            )
        else:
            cur = conn.execute("SELECT * FROM members ORDER BY name;")
        return [self._row_to_member(row) for row in cur.fetchall()]

    def delete_member(self, member_id: int) -> None:
        """Delete a member. Raises if the member has active loans."""
        with self._transaction() as cur:
            cur.execute(
                "SELECT COUNT(*) FROM loans WHERE member_id = ? AND returned = 0;",
                (member_id,),
            )
            active = cur.fetchone()[0]
            if active > 0:
                raise ValueError(
                    f"Cannot delete member {member_id}: they have {active} active loan(s)."
                )
            cur.execute("DELETE FROM loans WHERE member_id = ?;", (member_id,))
            cur.execute("DELETE FROM members WHERE id = ?;", (member_id,))
            if cur.rowcount == 0:
                raise LookupError(f"Member with id {member_id} not found.")

    # ------------------------------------------------------------------
    # Loan operations
    # ------------------------------------------------------------------

    def borrow_book(self, book_id: int, member_id: int) -> Loan:
        """
        Create a loan for *book_id* to *member_id*.

        Raises:
            LookupError  – if book or member does not exist.
            ValueError   – if book is unavailable or member has reached limit.
        """
        # Verify book exists and is available
        book = self.get_book(book_id)
        if book is None:
            raise LookupError(f"Book with id {book_id} not found.")
        if not book.available:
            raise ValueError(f"Book '{book.title}' (id {book_id}) is not available.")

        # Verify member exists
        member = self.get_member(member_id)
        if member is None:
            raise LookupError(f"Member with id {member_id} not found.")

        # Check how many books the member currently has
        conn = self._get_connection()
        cur = conn.execute(
            "SELECT COUNT(*) FROM loans WHERE member_id = ? AND returned = 0;",
            (member_id,),
        )
        active_count = cur.fetchone()[0]
        if active_count >= MAX_BOOKS_PER_MEMBER:
            raise ValueError(
                f"Member '{member.name}' already has {active_count} book(s) checked out "
                f"(limit: {MAX_BOOKS_PER_MEMBER})."
            )

        today = date.today()
        due = today + timedelta(days=LOAN_PERIOD_DAYS)

        loan = Loan(
            book_id=book_id,
            member_id=member_id,
            loan_date=today,
            due_date=due,
        )
        loan.validate()

        with self._transaction() as cur:
            cur.execute(
                "INSERT INTO loans (book_id, member_id, loan_date, due_date, returned, returned_date) "
                "VALUES (?, ?, ?, ?, 0, NULL);",
                (loan.book_id, loan.member_id, loan.loan_date.isoformat(), loan.due_date.isoformat()),
            )
            loan.id = cur.lastrowid
            # Mark the book as unavailable
            cur.execute("UPDATE books SET available = 0 WHERE id = ?;", (book_id,))

        return loan

    def return_book(self, loan_id: int) -> Loan:
        """
        Mark a loan as returned. Sets returned_date to today and makes the
        book available again.

        Raises:
            LookupError – if loan does not exist or is already returned.
        """
        conn = self._get_connection()
        cur = conn.execute("SELECT * FROM loans WHERE id = ?;", (loan_id,))
        row = cur.fetchone()
        if row is None:
            raise LookupError(f"Loan with id {loan_id} not found.")
        if row["returned"]:
            raise ValueError(f"Loan {loan_id} has already been returned.")

        today = date.today()
        with self._transaction() as txn_cur:
            txn_cur.execute(
                "UPDATE loans SET returned = 1, returned_date = ? WHERE id = ?;",
                (today.isoformat(), loan_id),
            )
            txn_cur.execute(
                "UPDATE books SET available = 1 WHERE id = ?;",
                (row["book_id"],),
            )

        # Re-fetch to return the updated loan
        cur = conn.execute("SELECT * FROM loans WHERE id = ?;", (loan_id,))
        updated_row = cur.fetchone()
        assert updated_row is not None
        return self._row_to_loan(updated_row)

    def get_loan(self, loan_id: int) -> Optional[Loan]:
        """Return a single Loan by id, or None if not found."""
        conn = self._get_connection()
        cur = conn.execute("SELECT * FROM loans WHERE id = ?;", (loan_id,))
        row = cur.fetchone()
        return self._row_to_loan(row) if row else None

    def list_loans(
        self,
        member_id: Optional[int] = None,
        book_id: Optional[int] = None,
        active_only: bool = False,
    ) -> List[Loan]:
        """
        List loans with optional filters.

        Parameters:
            member_id   : filter by member.
            book_id     : filter by book.
            active_only : if True, only show unreturned loans.
        """
        clauses: List[str] = []
        params: List[object] = []

        if member_id is not None:
            clauses.append("member_id = ?")
            params.append(member_id)
        if book_id is not None:
            clauses.append("book_id = ?")
            params.append(book_id)
        if active_only:
            clauses.append("returned = 0")

        sql = "SELECT * FROM loans"
        if clauses:
            sql += " WHERE " + " AND ".join(clauses)
        sql += " ORDER BY loan_date;"

        conn = self._get_connection()
        cur = conn.execute(sql, params)
        return [self._row_to_loan(row) for row in cur.fetchall()]

    def get_active_loans_for_member(self, member_id: int) -> List[Loan]:
        """Convenience wrapper: all unreturned loans for a member."""
        return self.list_loans(member_id=member_id, active_only=True)

    def get_overdue_loans(self) -> List[Loan]:
        """Return all loans that are overdue as of today."""
        conn = self._get_connection()
        today_iso = date.today().isoformat()
        cur = conn.execute(
            "SELECT * FROM loans WHERE returned = 0 AND due_date < ? ORDER BY due_date;",
            (today_iso,),
        )
        return [self._row_to_loan(row) for row in cur.fetchall()]

    # ------------------------------------------------------------------
    # Statistics
    # ------------------------------------------------------------------

    def stats(self) -> dict:
        """Return a summary dictionary of library statistics."""
        conn = self._get_connection()
        total_books = conn.execute("SELECT COUNT(*) FROM books;").fetchone()[0]
        available_books = conn.execute(
            "SELECT COUNT(*) FROM books WHERE available = 1;"
        ).fetchone()[0]
        total_members = conn.execute("SELECT COUNT(*) FROM members;").fetchone()[0]
        total_loans = conn.execute("SELECT COUNT(*) FROM loans;").fetchone()[0]
        active_loans = conn.execute(
            "SELECT COUNT(*) FROM loans WHERE returned = 0;"
        ).fetchone()[0]
        overdue = conn.execute(
            "SELECT COUNT(*) FROM loans WHERE returned = 0 AND due_date < ?;",
            (date.today().isoformat(),),
        ).fetchone()[0]
        return {
            "total_books": total_books,
            "available_books": available_books,
            "total_members": total_members,
            "total_loans": total_loans,
            "active_loans": active_loans,
            "overdue_loans": overdue,
        }
```

## File 3: `cli.py` — Command-Line Interface

```python
"""
cli.py
------
Command-line interface for the Library Management System.

Usage:
    python cli.py <command> [arguments]

Commands:
    add-book    --title T --author A --isbn I
    list-books  [--search S]
    get-book    <book_id>
    update-book <book_id> --title T --author A --isbn I
    delete-book <book_id>

    add-member  --name N --email E
    list-members [--search S]
    get-member  <member_id>
    delete-member <member_id>

    borrow      <book_id> <member_id>
    return      <loan_id>
    list-loans  [--member M] [--book B] [--active]
    get-loan    <loan_id>
    overdue

    stats

Exit codes:
    0 – success
    1 – user error / validation failure
    2 – unexpected error
"""

from __future__ import annotations

import argparse
import sys
from datetime import date

from models import Book, Member, Loan, LOAN_PERIOD_DAYS, MAX_BOOKS_PER_MEMBER
from store import LibraryStore


# ---------------------------------------------------------------------------
# Output formatting helpers
# ---------------------------------------------------------------------------

def _print_book(book: Book) -> None:
    status = "Available" if book.available else "Checked out"
    print(f"  [{book.id:>4}] {book.title}  by  {book.author}  (ISBN {book.isbn})  [{status}]")


def _print_member(member: Member) -> None:
    print(f"  [{member.id:>4}] {member.name}  <{member.email}>  joined {member.joined_on}")


def _print_loan(loan: Loan, books: dict[int, Book], members: dict[int, Member]) -> None:
    book = books.get(loan.book_id)
    member = members.get(loan.member_id)
    book_title = book.title if book else "Unknown book"
    member_name = member.name if member else "Unknown member"
    status = "Returned" if loan.returned else "Active"
    overdue_tag = " **OVERDUE**" if (not loan.returned and loan.is_overdue()) else ""
    print(
        f"  [{loan.id:>4}] '{book_title}' -> {member_name}  "
        f"loaned {loan.loan_date}  due {loan.due_date}  [{status}]{overdue_tag}"
    )


def _load_lookup_tables(store: LibraryStore) -> tuple[dict[int, Book], dict[int, Member]]:
    """Fetch all books and members into id-keyed dicts for display."""
    books = {b.id: b for b in store.list_books()}
    members = {m.id: m for m in store.list_members()}
    return books, members


# ---------------------------------------------------------------------------
# Command handlers
# ---------------------------------------------------------------------------

def cmd_add_book(store: LibraryStore, args: argparse.Namespace) -> None:
    book = store.add_book(args.title, args.author, args.isbn)
    print(f"Book added: id={book.id}  title='{book.title}'")


def cmd_list_books(store: LibraryStore, args: argparse.Namespace) -> None:
    books = store.list_books(search=args.search)
    if not books:
        print("No books found.")
        return
    print(f"{'ID':>4}  {'Title':<40}  {'Author':<25}  {'ISBN':<15}  Status")
    print("-" * 100)
    for b in books:
        _print_book(b)


def cmd_get_book(store: LibraryStore, args: argparse.Namespace) -> None:
    book = store.get_book(args.book_id)
    if book is None:
        print(f"Book with id {args.book_id} not found.", file=sys.stderr)
        sys.exit(1)
    _print_book(book)


def cmd_update_book(store: LibraryStore, args: argparse.Namespace) -> None:
    book = store.update_book(args.book_id, args.title, args.author, args.isbn)
    print(f"Book updated: id={book.id}  title='{book.title}'")


def cmd_delete_book(store: LibraryStore, args: argparse.Namespace) -> None:
    store.delete_book(args.book_id)
    print(f"Book {args.book_id} deleted.")


def cmd_add_member(store: LibraryStore, args: argparse.Namespace) -> None:
    member = store.add_member(args.name, args.email)
    print(f"Member added: id={member.id}  name='{member.name}'")


def cmd_list_members(store: LibraryStore, args: argparse.Namespace) -> None:
    members = store.list_members(search=args.search)
    if not members:
        print("No members found.")
        return
    print(f"{'ID':>4}  {'Name':<30}  {'Email':<30}  Joined")
    print("-" * 80)
    for m in members:
        _print_member(m)


def cmd_get_member(store: LibraryStore, args: argparse.Namespace) -> None:
    member = store.get_member(args.member_id)
    if member is None:
        print(f"Member with id {args.member_id} not found.", file=sys.stderr)
        sys.exit(1)
    _print_member(member)


def cmd_delete_member(store: LibraryStore, args: argparse.Namespace) -> None:
    store.delete_member(args.member_id)
    print(f"Member {args.member_id} deleted.")


def cmd_borrow(store: LibraryStore, args: argparse.Namespace) -> None:
    loan = store.borrow_book(args.book_id, args.member_id)
    book = store.get_book(args.book_id)
    member = store.get_member(args.member_id)
    print(
        f"Loan created: id={loan.id}  book='{book.title}' (id {book.id})  "

    "list-books":   cmd_list_books,

    "update-book":  cmd_update_book,
    "delete-book":  cmd_delete_book,
    "add-member":   cmd_add_member,
    "list-members": cmd_list_members,
    "get-member":   cmd_get_member,
    "delete-member": cmd_delete_member,
    "borrow":       cmd_borrow,
    "return":       cmd_return,

    "get-loan":     cmd_get_loan,
    "overdue":      cmd_overdue,
    "stats":        cmd_stats,
}


def main(argv: list[str] | None = None) -> int:
    parser = build_parser()
    args = parser.parse_args(argv)

    if args.command is None:
        parser.print_help()
        return 1

    handler = COMMAND_MAP.get(args.command)
    if handler is None:
        print(f"Unknown command: {args.command}", file=sys.stderr)
        return 1

    store = LibraryStore()
    try:
        handler(store, args)
        return 0
    except (ValueError, LookupError) as exc:
        # User-facing errors (bad input, not-found, etc.)
        print(f"Error: {exc}", file=sys.stderr)
        return 1
    except Exception as exc:
        # Unexpected errors – log and exit with code 2
        print(f"Unexpected error: {exc}", file=sys.stderr)
        return 2
    finally:
        store.close()


if __name__ == "__main__":
    sys.exit(main())

import sys

from contextlib import redirect_stdout, redirect_stderr

from store import LibraryStore

    """

    """

    def setUp(self) -> None:
        # Monkey-patch LibraryStore.__init__ to always use in-memory DB.
        # This avoids file-system side-effects during tests.
        self._orig_init = LibraryStore.__init__
        LibraryStore.__init__ = lambda self, db_path=":memory:": self._orig_init(self, ":memory:")

        LibraryStore.__init__ = self._orig_init

        """Run cli.main(argv) and return (exit_code, stdout, stderr)."""

        err_buf = io.StringIO()
        with redirect_stdout(out_buf), redirect_stderr(err_buf):
            code = cli.main(argv)
        return code, out_buf.getvalue(), err_buf.getvalue()

# Library Management System

A small, self-contained library management system written in pure Python
with SQLite persistence and a command-line interface.

## Files

| File              | Purpose                                      |
|-------------------|----------------------------------------------|
| `models.py`       | Data classes: Book, Member, Loan             |
| `store.py`        | SQLite persistence layer (CRUD + loans)      |
| `cli.py`          | Command-line interface                       |
| `test_models.py`  | Unit tests for data model                    |
| `test_store.py`   | Unit tests for the store layer               |
| `test_cli.py`     | Integration tests for the CLI                |
| `requirements.txt`| Dependencies (none – stdlib only)            |

## Quick Start

```bash
# No installation needed – Python 3.10+ standard library only.
python cli.py add-book --title "Dune" --author "Frank Herbert" --isbn "9780441172719"
python cli.py add-member --name "Alice" --email "alice@example.com"
python cli.py borrow 1 1
python cli.py list-loans --active
python cli.py return 1
python cli.py stats
```

## Running Tests

```bash
# With unittest (stdlib)
python -m unittest discover -v

# With pytest (install pytest first)
pip install pytest
pytest -v
```

## Architecture Overview

```
cli.py  ──►  store.py  ──►  SQLite (library.db)
              ▲
              │
          models.py   (pure data, no I/O)
```

- **models.py** defines plain dataclasses with validation methods.
- **store.py** owns all SQL, schema creation, and transaction handling.
- **cli.py** parses arguments, calls store methods, and formats output.
- Tests use an in-memory SQLite database (`:memory:`) so they are fast and isolated.
```
