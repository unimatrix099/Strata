Strata is an open-source inference engine that enables large Mixture-of-Experts models like Qwen3.8-Flash-Next to run on consumer hardware by distributing the workload across the GPU, RAM, and SSD, utilizing techniques such as speculative decoding and adaptive expert caching. The software supports both NVIDIA and AMD GPUs on Windows and Linux, offering flexible installation options including native scripts, Docker containers, and multi-GPU configurations to optimize performance based on available system resources. Comprehensive documentation covers detailed troubleshooting, API usage with structured output support, and technical explanations of how the system balances memory tiers to maintain high generation speeds and quality.
