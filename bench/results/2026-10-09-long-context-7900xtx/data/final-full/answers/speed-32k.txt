Strata is a local inference engine that enables large Mixture-of-Experts models to run on consumer hardware by distributing computational workloads across the GPU, CPU, and RAM, utilizing an adaptive expert cache and speculative decoding to optimize speed and memory usage. The system supports various API interfaces, including OpenAI, Anthropic, and MCP protocols, while offering advanced features like conversation caching, session persistence, and vision capabilities through configurable settings and Docker support. Performance is enhanced through specific optimizations such as prompt buffer sharing, expert exchange rotation, and CPU-GPU task balancing, all of which are documented with detailed benchmarks and troubleshooting guides for different hardware configurations.
