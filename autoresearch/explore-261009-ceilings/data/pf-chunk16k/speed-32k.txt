Strata is a local AI inference engine optimized for running large quantized models like Qwen3.8-Flash-Next on consumer hardware by utilizing a hybrid CPU-GPU architecture that stores model experts in RAM or disk while processing active tokens on the GPU. The documentation details extensive configuration options for managing memory constraints, including low-RAM modes, KV cache streaming, and adaptive expert caching, alongside comprehensive API support for OpenAI and Anthropic standards, tool calling, and multi-GPU setups. Performance metrics and community benchmarks are provided to guide users in selecting appropriate model quantizations and hardware configurations to achieve optimal prompt processing and token generation speeds.
